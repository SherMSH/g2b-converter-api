## О проекте

**G2B Converter API** — сервис-адаптер между SOAP/XML протоколом **Compass Plus (TWO/FIMI)** и REST/JSON API процессинга **D8 G2B (Humo)**. Пользователи — банки-партнёры (сейчас Arvand), чьи системы говорят на FIMI, тогда как процессинг принимает JSON.

**Основная задача:** принять запрос партнёра в формате Compass, преобразовать его в вызовы D8, собрать ответ обратно в FIMI-XML. Два канала: ONLINE (синхронный SOAP) и OFFLINE (пакетные XML-файлы, обрабатываются планировщиком).

**Статус:** `в продакшене`

## Quick Start

```bash
# 1. Клонировать репозиторий
git clone git@gitlab.humo.tj:MustafokulovSh/g2b-converter-api.git
cd g2b-converter-api

# 2. Установить зависимости
go mod download

# 3. Настроить конфигурацию
#    Файл internal/config/config.json уже в репозитории.
#    Проверить processing.address — адрес стенда D8.

# 4. Собрать
go build -o converterApi cmd/main.go

# 5. Запустить (обязательно из корня проекта — пути к конфигу и ключам относительные)
./converterApi
```

Внешних зависимостей для локального запуска нет: ни БД, ни брокера, ни кеша. Нужен только доступ к стенду D8 (`processing.address`), иначе сервис поднимется, но все операции будут отдавать ошибку.

После запуска:
- API: `http://localhost:8086`
- Health-check: `GET /g2b/ping` (требует API-ключ)
- Метрики: `GET /metrics`

Подробнее про окружения и деплой — в [Deployment.md](./Deployment.md).

## Что важно знать сразу

- **Состояния у сервиса нет.** Ни БД, ни кеша, ни очередей: `internal/repository` — пустая структура. Всё живёт в D8 и в файлах на диске.
- **Слои формальны.** Цепочка `repository → service → handlers` собирается в `app.New()`, но реальная логика лежит в пакетных функциях, а не в методах `Service`. См. [Architecture.md](./Architecture.md).
- **Тип ONLINE-запроса определяется по имени корневого тега** тела SOAP, а не по URL: один эндпоинт `POST /g2b/d8convert` обслуживает 20+ операций.
- **Два разных транспорта до процессинга**: прямые вызовы `/xapi/*` и сессионный портал `/api/*` с cookie. См. [Integrations.md](./Integrations.md).
- **Автотестов нет.** Проверка ограничивается `go build ./...` и `go vet ./...`.
